Politique de confidentialité — ClipShine

Dernière mise à jour : mars 2026

1. Nature de l'application

ClipShine est un outil local personnel. L'application s'exécute entièrement sur votre propre machine et ne collecte, ne transmet ni ne stocke aucune donnée sur des serveurs tiers.

2. Données TikTok

ClipShine utilise l'API TikTok uniquement pour envoyer des vidéos en brouillon sur votre propre compte TikTok, avec votre consentement explicite via le processus d'autorisation OAuth de TikTok. Les tokens d'accès sont stockés localement sur votre machine uniquement.

3. Données collectées

Aucune donnée personnelle n'est collectée ou partagée avec des tiers. Toutes les données (vidéos, clips, tokens) restent sur votre appareil local.

4. Contact

Pour toute question, contactez le développeur directement via GitHub.
